# 1.0.0 验证范围

以下四组各执行 18 项测试，全部通过：

| 环境 | 普通物品 / 末影珍珠 / 工具上限 |
| --- | --- |
| 只安装 Tom's Storage 与必要依赖 | 游戏默认值 |
| 同时安装 TVSN 1.0.0 | 游戏默认值 |
| TVSN 与堆叠调整模组 | 128 / 32 / 1 |
| TVSN 与堆叠调整模组 | 256 / 48 / 4 |

验证内容包括动态最大堆叠、物品数据组件、一个源格传输、目标空间不足、基础漏斗与曲率漏斗的成功传输间隔、红石、过滤、锻造配方、保存恢复和正确掉落。

持续少量补货、源耗尽再补货、完整连接器接法、远端连接器区块及漏斗区块实际卸载/重载也在测试中。恢复后核对真实数量，并确认不需要拆除重放漏斗。

测试只在独立世界运行。没有执行或上传玩家整合包，没有做大量漏斗的 TPS 压测，也没有覆盖所有第三方机器和真实多客户端组合。

对旧 TVSN 0.2.2-dev 的兼容补丁保留开发版中已验证的版本门槛。曲率漏斗的四个正式类与 0.1.2-dev 逐字节比对；发布不改变其传输逻辑。

正式 JAR、源码和测试摘要见 [verification.json](test-results/1.0.0/verification.json)。Release 另外提供 `SHA256SUMS.txt`。

独立客户端还验证了真实终端界面的数量、取出与重新存入，以及木桶激活状态和材质；曲率漏斗截图由该客户端实际拍摄。测试进程使用了专用 JVM 参数，不能据此认定其他环境的客户端异常退出已经解决。
